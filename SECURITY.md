# Security policy

Do not open a public issue for a vulnerability. Use
[private vulnerability reporting](https://github.com/Verahelm/verahelm-decision-envelope/security/advisories/new).
The [security page](https://www.verahelm.com/security) provides the current
contact and handling policy.

Include the affected public revision, a fictional reproduction, and impact. Do
not send credentials, real envelopes, customer data, prompts, logs, production
URLs, or proprietary material.

Supported public line: `0.10.x` until a later release states otherwise.
