# Public roadmap

Accepted work remains inside the public verification boundary:

- conformance vectors for revocation and supersession;
- deterministic adapters that output digest references only;
- additional language-independent canonicalization vectors;
- verifier portability tests;
- documentation corrections and threat-model cases.

Out of scope: evaluation logic, scoring, evidence interpretation, hosted-service internals, production configuration, customer data, and deployment policy.

Use Discussions for contract questions. Use the adapter-request template for proposed evidence producers.
